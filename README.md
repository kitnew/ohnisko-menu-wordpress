# Ohnisko Menu

WordPress menu data and print HTML with a separate Node/Chromium PDF worker. The responsibilities, field schema, protected print contract, brand rules, job lifecycle, publication/history behavior, and verification commands are documented in [docs/architecture.md](docs/architecture.md).

The administrator edits menu items and generates PDF jobs. A ready PDF is previewable and downloadable; publishing a selected version is a separate action. The stable public menu address is `/?ohnisko_menu=1`.
